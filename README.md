# React Registration Form

A modern and responsive registration form built with **React** and **Vite**, focused on controlled components, form state management, validation, and user-friendly feedback.

## 🚀 Live Demo

https://react-registration-form-zeta.vercel.app/

## 📌 Overview

This project was built as part of **Project Alpha — Week 4** to strengthen practical React development skills through a real-world form application.

The application demonstrates how React can manage user input, validate form data, handle different input types, and provide immediate feedback without traditional page reloads.

## ✨ Features

* Controlled React form inputs
* Centralized form state using `useState`
* Dynamic input handling with a reusable `handleChange` function
* Email validation
* Password length validation
* Confirm password matching
* Role selection
* Terms & conditions checkbox
* Field-specific error messages
* Success state after valid submission
* Responsive design
* Input focus states
* Button hover interactions
* Mobile-friendly layout

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/anshxit/React-Registration-Form.git
```

### 2. Navigate into the project

```bash
cd React-Registration-Form
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## 🧪 Validation

The form validates:

* Required fields
* Email format
* Minimum password length
* Password confirmation
* Role selection
* Terms & conditions acceptance

After successful validation, the application displays a confirmation message to the user.

## 📱 Responsive Design

The interface is designed to work across:

* Desktop
* Tablet
* Mobile

The layout adjusts automatically for smaller screen sizes.

## 🎯 Project Goal

The goal of this project was to move beyond basic React syntax and understand how React handles **real user input and application state**.

It serves as a foundation for building more advanced applications involving authentication, API integration, dashboards, checkout flows, and other data-driven interfaces.
